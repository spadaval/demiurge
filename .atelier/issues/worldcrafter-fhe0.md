## Goal

The long runs need a premise nobody building the harness or rubric has read, so that neither can be tuned to it. Done the same way as the second comparison's held-back premise (decision worldcrafter-kkmy).

## Done when

- A fresh agent that builds nothing in worldcrafter-efis chooses one premise, about as open as the earlier ones (a phrase or a short paragraph, any genre). It must not be Thukker, magical girl therapist or premise-c.
- The agent writes the premise to a sealed file in a new run root outside the repository. A decision record names the file and its sha256, not the text.
- A second fresh agent, which also builds nothing, reviews the premise against that record.
- Nobody working on the rubric or the harness reads the premise before the runs.
